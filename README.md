# Formulario de entrevista · 333 Jobs

Formulario bilingüe (ES/EN) de entrevista de 333 Jobs. Al enviarlo, la persona inicia sesión con su cuenta de 333 y la respuesta se agrega como fila en el Excel **"formulario entrevistado ingles.xlsx"** (tabla `Respuestas`) del sitio de SharePoint **333 Recruitment**.

- `index.html`: formulario.
- `redirect.html`: página de retorno del inicio de sesión de Microsoft.
- `msal-browser.min.js`: librería oficial de Microsoft para el inicio de sesión (MSAL.js 3.27.0).
